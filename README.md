# Utopia Room Rental iBilik Auto Poster: downloads

The app Utopia Room Rental's team uses to post available rooms to iBilik. It does nothing
until you sign in with your own Room Rental and iBilik accounts.

## Download

Get the newest version from **[Releases → Latest](../../releases/latest)**:

| Your computer | File |
|---|---|
| Windows 10 or 11 | `Utopia-iBilik-Auto-Poster-Setup.exe` |
| Mac with Apple chip (M1 or newer) | `Utopia-iBilik-Auto-Poster-AppleSilicon.dmg` |
| Mac with Intel processor | `Utopia-iBilik-Auto-Poster-Intel.dmg` |

Not sure which Mac? Apple menu → **About This Mac**: "Chip: Apple M…" or "Processor: Intel".

## Install

**Windows:** run the Setup file. If Windows says it protected your PC, click
**More info → Run anyway** (only the first time). It installs for you (no admin needed),
adds **Utopia Room Rental iBilik Auto Poster** to the Start menu and desktop, and opens it.

**Mac:** open the `.dmg` and drag the app into **Applications**, then open it from there.
If macOS says it can't verify the developer, go to **System Settings → Privacy & Security →
Open Anyway** (only the first time).

Google Chrome must be installed (Microsoft Edge also works on Windows).

## First time

In the app's page that opens in your browser:
1. **Log in to iBilik**: a Chrome window opens; sign in yourself.
2. **Connect Room Rental**: your Room Rental email and password (used once, not stored).

Then use **Room Rental → gear → Post to iBilik** to preview or post. The app starts by
itself when you log in to your computer, so the buttons always reach it.
